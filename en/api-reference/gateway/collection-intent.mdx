## Amount unit

Send `amount` in major units by default: `4.01` for 4.01 USD/EUR. API clients that already send cents can set `amount_unit: "MINOR"` at the root of the JSON body, alongside `amount` and `currency`, rather than in `metadata`. Public responses return major units even when the request uses `MINOR`. See [amounts and currencies](/en/api-docs/monetary-units).

Set `amount_unit` when creating the intent. Subsequent `execute` and `status` requests use `transaction_reference` and do not accept a replacement amount.

### USD example

This intent example uses major units. Choose a provider authorized for the operation and currency.

```json
{
  "amount": 4.01,
  "currency": "USD",
  "amount_unit": "MAJOR",
  "transaction_uuid": "2f8b9a68-1ad3-4a0c-a187-40b91a4c44a1",
  "provider": "YOUR_USD_PROVIDER",
  "channel": "PROVIDER",
  "customer_wallet": "YOUR_CUSTOMER_WALLET"
}
```

If your client stores cents, replace only the monetary input with `"amount": 401` and `"amount_unit": "MINOR"`. Both representations target 4.01 USD; public responses remain in major units.
