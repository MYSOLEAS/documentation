---
title: "Get a user JWT"
description: "Exchange an OAuth2 code for a Mysoleas Identity Cloud user JWT."
openapi: "/en/api-reference/openapi.json POST /oauth/v2/token"
---

This endpoint returns a Mysoleas Identity Cloud user JWT.

For a user sign-in, call it after `/oauth/v2/authorize` with the OAuth `code` and PKCE `code_verifier`.

Once you have the JWT, you can use it to open a session in your application or call `userinfo`.

<Note>
  To consume SoleasPay gateway endpoints, use the credentials of the application created in SoleasPay to get an application token, then send it in `x-sp-auth-token`.
</Note>
