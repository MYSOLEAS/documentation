---
title: "Retrieve a Single Route — GET /routes/{route_id}"
sidebarTitle: "Get Route"
description: "Fetch the full configuration of a single route using its unique ID, including its path, methods, upstream URL, and current status."
---

Retrieving a route by its ID returns the complete configuration for that route, including all path-matching rules, the upstream target, and the current operational status. Use this endpoint when you need to inspect or verify a specific route's settings.

**Endpoint**

```
GET https://api.mysoleas.io/v1/routes/{id}
```

## Path Parameters

<ParamField path="id" type="string" required>
  The unique identifier of the route you want to retrieve (e.g., `rt_xyz789`).
</ParamField>

## Example Request

```bash
curl --request GET \
  --url "https://api.mysoleas.io/v1/routes/rt_xyz789" \
  --header "Authorization: Bearer YOUR_API_KEY"
```

## Response

Returns `200 OK` with the full route object.

```json
{
  "id": "rt_xyz789",
  "gateway_id": "gw_abc123",
  "name": "main-api",
  "path": "/api/v1",
  "methods": ["GET", "POST", "PUT", "DELETE"],
  "upstream": "https://api.example.com",
  "strip_path": true,
  "preserve_host": false,
  "status": "active",
  "priority": 1,
  "created_at": "2024-01-15T10:00:00Z",
  "updated_at": "2024-01-15T10:00:00Z"
}
```

## Response Fields

<ResponseField name="id" type="string">
  The unique identifier of the route.
</ResponseField>

<ResponseField name="gateway_id" type="string">
  The identifier of the gateway this route belongs to.
</ResponseField>

<ResponseField name="name" type="string">
  The human-readable name of the route.
</ResponseField>

<ResponseField name="path" type="string">
  The URL path prefix this route matches against incoming requests.
</ResponseField>

<ResponseField name="methods" type="array of strings">
  The list of HTTP methods this route is configured to accept.
</ResponseField>

<ResponseField name="upstream" type="string">
  The HTTPS URL of the upstream service that matched requests are forwarded to.
</ResponseField>

<ResponseField name="strip_path" type="boolean">
  Whether the matched path prefix is stripped from the request before forwarding to the upstream.
</ResponseField>

<ResponseField name="preserve_host" type="boolean">
  Whether the original client `Host` header is passed to the upstream.
</ResponseField>

<ResponseField name="status" type="string">
  The current status of the route. Either `active` or `inactive`.
</ResponseField>

<ResponseField name="priority" type="integer">
  The route matching priority. Lower numbers indicate higher priority.
</ResponseField>

<ResponseField name="created_at" type="string">
  ISO 8601 timestamp of when the route was created.
</ResponseField>

<ResponseField name="updated_at" type="string">
  ISO 8601 timestamp of when the route was last updated.
</ResponseField>
