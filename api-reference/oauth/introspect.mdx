---
title: "Introspecter un token"
description: "Verifier l'etat, les scopes et les claims d'un JWT Mysoleas."
openapi: "POST /oauth/v2/introspect"
---

Utilisez l'introspection lorsqu'un backend doit verifier explicitement qu'un token est actif, connaitre ses scopes ou controler son contexte avant une operation sensible.
