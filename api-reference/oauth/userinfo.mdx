---
title: "Lire le profil utilisateur"
description: "Recuperer les claims de l'utilisateur connecte avec Mysoleas."
openapi: "GET /oauth/v2/userinfo"
---

Utilisez `userinfo` apres une connexion OAuth2 pour afficher ou synchroniser le profil de l'utilisateur connecte.

Les claims retournes peuvent inclure l'identifiant utilisateur, l'email, le statut de verification, le tenant marchand et les informations utiles au contexte applicatif.
