La reference API de Mysoleas est organisee autour de l'infrastructure commune et des corps de metier.

| Couche | Serveur | URL | Role |
| --- | --- | --- | --- |
| Infrastructure | Gateway | `https://api.mysoleas.com` | Route les appels vers les services metier |
| Infrastructure | Mysoleas Identity Cloud | `https://account.mysoleas.com` | OAuth2/OIDC, bouton **Se connecter avec Mysoleas**, gestion utilisateur, JWT utilisateur et userinfo |
| Metier | SoleasPay | via `api.mysoleas.com` | Paiements, liens, souscriptions, collections, disbursements, pays, services et providers |

Mysoleas Identity Cloud peut etre integre seul pour gerer l'authentification et les utilisateurs d'une application tierce. Dans ce cas, votre application utilise `account.mysoleas.com`, valide le JWT utilisateur, lit `userinfo`, puis continue avec ses propres APIs.

Pour creer une application OAuth2, connectez-vous au dashboard Mysoleas:

```txt
https://mysoleas.com
```

Les routes gateway protegees utilisent le header suivant avec un token obtenu depuis une application creee dans SoleasPay:

```txt
x-sp-auth-token: Bearer <access_token>
```

Ce token est obtenu avec le `client_id` et le `client_secret` de l'application creee dans SoleasPay. Il est distinct du JWT utilisateur emis par Mysoleas Identity Cloud.

<Note>
  Les endpoints Identity Cloud vivent sur `account.mysoleas.com`. Les endpoints gateway SoleasPay utilisent un token obtenu depuis une application creee dans SoleasPay. Les plugins SoleasPay v4 utilisent une `apikey` marchand et ne demandent pas ce header.
</Note>

La route publique de paiement par lien exposee dans cette reference est:

- `POST https://api.mysoleas.com/pay/{shortCode}/pay` pour soumettre le paiement.

## Format de succes

```json
{
  "code": 200,
  "success": true,
  "data": {},
  "locale": "fr",
  "message": "transaction_submitted"
}
```

## Format d'erreur

```json
{
  "success": false,
  "code": 400,
  "message": "empty_data"
}
```

## Pagination

Les listes acceptent generalement `page` et `limit`. La reponse peut contenir `meta.pagination`.

```json
{
  "pagination": {
    "page": 1,
    "limit": 25,
    "total": 120,
    "pages": 5,
    "has_next": true,
    "has_previous": false
  }
}
```

## Montants en v4

Envoyez `amount` en valeur réelle par défaut : `4.01` pour 4,01 USD/EUR. Les clients API qui envoient déjà des centimes peuvent préciser `amount_unit: "MINOR"` à la racine du corps JSON, au même niveau que `amount` et `currency`, et non dans `metadata`. Les réponses publiques reviennent en valeur réelle même si la requête utilise `MINOR`. Consultez [les montants et devises](/api-docs/monetary-units).
