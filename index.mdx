Mysoleas expose une architecture API modulaire pour accepter des paiements, envoyer des fonds, creer des liens de paiement, gerer des souscriptions et brancher des plugins marchands sans coupler votre application aux microservices internes.

La nouvelle integration repose sur deux domaines publics:

| Domaine | Role |
| --- | --- |
| `https://api.mysoleas.com` | Gateway applicative pour les paiements, services, pays et providers |
| `https://account.mysoleas.com` | Authentification OAuth 2.0, jetons et informations utilisateur |

## Ce que vous pouvez construire

### Encaisser

Utilisez les collections pour demander un paiement au client. Mysoleas retourne une reference, pilote le provider et vous laisse suivre le statut jusqu'a l'etat final.

### Decaisser

Utilisez les disbursements pour envoyer des fonds depuis votre solde Mysoleas vers un wallet client. Le flux verifie le solde, reserve les fonds, execute le payout, puis synchronise le statut.

### Automatiser

Utilisez les souscriptions pour facturer un client a une frequence definie. Chaque paiement de souscription possede sa propre reference et son propre statut.

### Simplifier le checkout

Utilisez les liens de paiement pour creer une URL partageable. Le client paie sur une page publique, pendant que votre backend conserve la reference et suit l'evolution.

## Convention de reponse

Les APIs applicatives renvoient une enveloppe JSON stable.

```json
{
  "code": 200,
  "success": true,
  "data": {},
  "locale": "fr",
  "message": "transaction_submitted",
  "meta": {}
}
```

En cas d'erreur, `success` vaut `false` et `message` contient la raison exploitable par votre backend.

```json
{
  "success": false,
  "code": 400,
  "message": "empty_data"
}
```
