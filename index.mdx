Mysoleas expose une architecture modulaire pour connecter vos applications a plusieurs domaines metier sans les coupler aux microservices internes.

La plateforme se lit en deux couches:

- **l'infrastructure Mysoleas**, qui porte l'identite, la securite et la gateway;
- **les corps de metier**, qui portent les usages business comme le paiement, les ventes, les notifications et le marketing.

## Points d'entree publics

| Domaine | Role |
| --- | --- |
| `https://api.mysoleas.com` | Gateway applicative pour toutes les routes metier protegees |
| `https://account.mysoleas.com` | Mysoleas Identity Cloud: OAuth2, OIDC, JWT, profil utilisateur et bouton **Se connecter avec Mysoleas** |

Toutes les routes de la gateway attendent un JWT Bearer dans le header `x-sp-auth-token`.

```txt
x-sp-auth-token: Bearer <JWT>
```

<Note>
  Les plugins SoleasPay `Checkout v3` et `Button v3` sont l'exception volontaire: ils s'integrent avec une `apikey` marchand pour accelerer les integrations paiement.
</Note>

## Corps de metier Mysoleas

| Produit | Domaine | Ce que vous integrez |
| --- | --- | --- |
| SoleasPay | Payment service processor | Collections, disbursements, liens de paiement, souscriptions, services, pays et providers |
| Mysoleas Identity Cloud | Identité | Connexion OAuth2/OIDC, JWT, userinfo et applications tierces |
| MyShup | Ventes | Gestion et automatisation des ventes |
| Notification Service | Communication | Notifications transactionnelles et messages lies aux evenements |
| MyBoost | Marketing | Campagnes boost, Challenges |

## Ce que vous pouvez construire avec SoleasPay

### Encaisser

Utilisez les collections pour demander un paiement au client. Mysoleas retourne une reference, pilote le provider et vous laisse suivre le statut jusqu'a l'etat final.

### Decaisser

Utilisez les disbursements pour envoyer des fonds depuis votre solde Mysoleas vers un wallet client. Le flux verifie le solde, reserve les fonds, execute le payout, puis synchronise le statut.

### Automatiser

Utilisez les souscriptions pour facturer un client a une frequence definie. Chaque paiement de souscription possede sa propre reference et son propre statut.

### Simplifier le checkout

Utilisez les liens de paiement pour creer une URL partageable. Le client paie sur une page publique, pendant que votre backend conserve la reference et suit l'evolution.

### Integrer vite

Utilisez `Checkout v3` ou `Button v3` lorsque vous voulez ajouter SoleasPay dans une application tierce avec une `apikey`, sans gerer OAuth2 ni les appels gateway.

## Convention de reponse gateway

Les APIs applicatives renvoient une enveloppe JSON stable.

```json
{
  "code": 200,
  "success": true,
  "data": {},
  "locale": "fr",
  "message": "transaction_submitted",
  "meta": {}
}
```

En cas d'erreur, `success` vaut `false` et `message` contient la raison exploitable par votre backend.

```json
{
  "success": false,
  "code": 400,
  "message": "empty_data"
}
```
