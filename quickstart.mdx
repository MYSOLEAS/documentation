---
title: "Get Started with Mysoleas API Gateway Fast"
sidebarTitle: Quickstart
description: "Create your first Mysoleas gateway, add a route to an upstream service, and send a proxied request — all in under five minutes."
---

This guide walks you through the fastest path to a working API gateway. By the end, you'll have a live gateway endpoint that proxies requests to an upstream service, with all traffic visible in your analytics dashboard.

<Note>
  **Prerequisites:** You need a Mysoleas account and a management API key before you begin. If you don't have one yet, see [Authentication](/authentication) to generate your first API key.
</Note>

<Steps>
  <Step title="Create your first gateway">
    Send a `POST` request to `/gateways` to provision a new gateway instance. Replace `YOUR_API_KEY` with your management API key.

    <CodeGroup>
      ```bash cURL
      curl --request POST \
        --url https://api.mysoleas.io/v1/gateways \
        --header 'Authorization: Bearer YOUR_API_KEY' \
        --header 'Content-Type: application/json' \
        --data '{
          "name": "my-gateway",
          "description": "My first gateway"
        }'
      ```

      ```json Response
      {
        "id": "gw_abc123",
        "name": "my-gateway",
        "status": "active",
        "endpoint": "https://gw_abc123.mysoleas.io",
        "created_at": "2024-01-15T10:00:00Z"
      }
      ```
    </CodeGroup>

    Copy the `id` and `endpoint` from the response — you'll use both in the next steps.

    <Tip>
      The `endpoint` value is the public URL your consumers will call. Keep it handy.
    </Tip>
  </Step>

  <Step title="Add a route">
    Define a route that maps an inbound path on your gateway to an upstream URL. Replace `gw_abc123` with the gateway `id` you received above.

    <CodeGroup>
      ```bash cURL
      curl --request POST \
        --url https://api.mysoleas.io/v1/gateways/gw_abc123/routes \
        --header 'Authorization: Bearer YOUR_API_KEY' \
        --header 'Content-Type: application/json' \
        --data '{
          "name": "api-route",
          "path": "/api/v1",
          "upstream": "https://api.example.com",
          "methods": ["GET", "POST"]
        }'
      ```

      ```json Response
      {
        "id": "rt_xyz789",
        "name": "api-route",
        "path": "/api/v1",
        "upstream": "https://api.example.com",
        "status": "active"
      }
      ```
    </CodeGroup>

    Any `GET` or `POST` request to `https://gw_abc123.mysoleas.io/api/v1` will now proxy to `https://api.example.com`.
  </Step>

  <Step title="Make a request through the gateway">
    Call your gateway endpoint directly. Mysoleas forwards the request to the upstream URL and returns the response.

    <CodeGroup>
      ```bash cURL
      curl --request GET \
        --url https://gw_abc123.mysoleas.io/api/v1 \
        --header 'x-api-key: YOUR_API_KEY'
      ```

      ```json Response
      {
        "message": "Hello from your upstream service!",
        "status": 200
      }
      ```
    </CodeGroup>

    <Note>
      The `x-api-key` header here authenticates the **consumer** request through the gateway. This is separate from the `Authorization: Bearer` header used to manage the gateway via the REST API.
    </Note>
  </Step>

  <Step title="Verify in the dashboard">
    Open the [Mysoleas dashboard](https://dashboard.mysoleas.io) and navigate to **Gateways → my-gateway → Analytics**. You'll see the request you just made appear in the traffic log with status code, latency, and upstream response details.
  </Step>
</Steps>
